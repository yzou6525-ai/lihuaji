## 朋友如何修改

所有者打开 https://github.com/yzou6525-ai/lihuaji/settings/access ，点击 **Add people**，填写朋友的 GitHub 用户名。朋友接受邀请后即可编辑文件。未提供朋友用户名，因此尚未发送邀请。

- `content/site.json`：首页标题、简介、顶部提示。
- `content/patterns.json`：774份纹样说明、地区、原出处与许可。
- `content/products.json`：75件文创资料及2418个规格，仅展示，无交易。
- `app.js`：页面内容和交互；`style.css`、`pages.css`：样式。
- `assets/`：网页图片及浏览器运行库。

网页编辑：打开文件 → 铅笔图标 → 修改 → **Commit changes**。提交到 main 自动发布。若提交到其他分支，创建 Pull Request，审核并合并到 main 后发布。

发布进度：https://github.com/yzou6525-ai/lihuaji/actions 。`Publish GitHub Pages` 绿色成功后刷新网站；也可点此工作流 → **Run workflow** 手动发布。工作流会先检查目录与图片引用；失败时查看红色步骤，修复后再次提交。
