## 来源与筛选

本批图片来自[克利夫兰艺术博物馆开放资料](https://www.clevelandart.org/open-access)，每条馆方 API 记录的 `share_license_status` 均为 `CC0`，不是仅依据网站总体开放政策判断。具体原作及图片链接随条目保存。

检索了织物、刺绣、服饰、挂毯、地毯及部分传统人物图像。排除原目录 ID、已收录的同馆藏编号族以及早期明确剔除的记录。下载和尺寸筛选后逐项查看 376 幅候选的 16 张联系表，选入 264 幅。原图字节和显示图校验值无重复；256 位图像差异哈希与原库及新图对比，在距离 8 以内没有近似命中。该检查不能证明所有相似文化题材都不存在；相同主题的不同馆藏仍可保留。

同时核查了故宫、大都会及其他博物馆的开放条件或接口。故宫影像需要另行授权，本批未转载其图片；大都会与芝加哥艺术博物馆本次下载接口不可用，未把仅有元数据、没有可用图片的条目计入新增数量。

中文名称、标签和难度是本库的整理，不是馆方正式译名或专家鉴定。基础取样只建议提取清楚的单元，不代表整幅容易绣。本批未新增无来源的吉祥寓意、针法或工艺认证，也没有扩大故事生成的审核知识白名单。未知作者直接注明馆方未列出具名作者。

网页图保留原构图，只等比例缩小并转换 WebP；无裁切、重绘或调色。原始高分辨率图仍可从原作页面查看。

## 使用

- 在原“祥云纹样库”浏览，新增条目排在前面。
- 可按九地区及简易／复杂筛选，搜索中文题材、馆藏编号、原作英文名、年代或来源机构。
- 搜索 `museum-2026-10-11` 可单独查看本批 264 份。
- 点击纹样，展开“纹样资料与取样建议”，查看原作名称、年代、文化归属、技法与许可。
- 继续用原按钮进入译绣；导出的 SVG 保留来源与许可。配对挑战自动从同一目录选图。

## 核验文件

- `selection.json`：264 条入选清单、官方字段快照、图片哈希和原目录校验值。
- `selection-log.json`：376 幅候选的选入数量及未入选清单。
- `import-report.json`：导入数量、地区、题材、图片字节数。
- `browser-report.json`：本地浏览器实测结果。
- `library-desktop.png`、`library-mobile.png`：实际网页截图。

自动检查覆盖：至少 200 条、不重复 ID、原有 774 条逐字段保留、来源与 CC0 快照一致、九地区与题材覆盖、528 张 WebP 字节校验。浏览器检查实际解码所有新图，测试筛选、原作详情、带来源的 SVG 下载、手机滚动图片载入和游戏使用新图。

```sh
npm test
npm run build
node scripts/library-acceptance.cjs
```

浏览器测试仅维护者需要 Playwright 与 Edge；网站访客无需安装。正式网页为 GitHub Pages 静态资源，图片不依赖作者电脑或馆方即时图床响应。

如需重新生成同一批压缩图，Python 3、Pillow 与 curl 环境中运行：

```sh
python scripts/import-museum-patterns.py --cache PATH_TO_IMAGE_CACHE
```

该脚本仅读取已筛选清单，重复执行会替换本批，保留原目录。下载原图哈希变化时停止，需重新核对来源。`--cache` 指向原 JPG 缓存；不需要将缓存或私人文件提交 GitHub。
