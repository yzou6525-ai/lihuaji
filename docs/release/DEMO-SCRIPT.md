# 项目演示脚本（约 110–120 秒）

| 时间 | 画面 / 操作 | 讲解要点 |
|---|---|---|
| 00–10 秒 | 首页与项目名称 | 梨花季把苏绣课程、知识、数字练习与作品观察入口串在一起。 |
| 10–25 秒 | 进入 `#ar/learn-tao`，展示五步学习路径 | 从官方课程开始，路径进度只记录进入或完成数字练习，不代表学会传统针法。 |
| 25–40 秒 | 点击套针课程节点，选中 `mooc-suxiu-02` | 展示原课程目录。课程播放与登录由中国大学 MOOC 控制。 |
| 40–55 秒 | 打开 `stitch-tao` 知识档案 | 展示知识条目与来源链接，说明档案用于查阅，不取代师承教学。 |
| 55–75 秒 | Stitch Lab：逐针、针落点、Stitch Plan、缩放与Fit | 选择项目数字套针练习；演示逐步推进与视图控制，并说明针路为数字示意。 |
| 75–95 秒 | 选散套针，打开针迹计划并播放约 11 秒数字显影；切换 AR 页面 | 说明 56 针与 11 秒为项目数字设计参数。AR需要实际手机相机授权；若现场设备未测试，应明确演示的是浏览器预览。 |
| 95–108 秒 | Ricuci 卡片与打开按钮 | 展示第三方机器刺绣工具入口；文件处理与格式能力由 Ricuci 提供。 |
| 108–120 秒 | 回到来源/真实性说明 | 区分官方资料、项目数字示意、机器刺绣与苏绣手工针法；说明当前真机验收状态。 |

演示者不得将自动化截图、合成相机流或浏览器模拟视口描述为真实手机验收。
