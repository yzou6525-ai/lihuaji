# AR技术证明短视频脚本（20–30 秒）

此脚本用于**未来实体手机实测**。当前没有实体录制素材；不要把本脚本或自动化测试截图当作已完成的视频证据。

1. 0–4 秒：镜头拍到真实手机屏幕和手机型号/浏览器，打开 Pages 的 `#ar`，展示正在使用后置摄像头。
2. 4–8 秒：授权相机，对准梨花识别卡；说明目标是屏幕显示还是打印卡，并记录首次识别耗时与光线。
3. 8–13 秒：进入“看针”，选择前层花瓣或金色热点，启动散套数字显影。
4. 约 13 秒（显影播放约 5 秒）：把目标移出视野约 2 秒，展示时间线暂停且进度保留。
5. 约 15–22 秒：重新对准同一识别卡，展示从原位置继续；再手动暂停、移开并重新识别，确认不会自动续播。
6. 22–27 秒：退出显影，确认原梨花层恢复；录入设备、浏览器、结果和失败现象。

只有真实设备视频和记录完成后，才能将 camera、tracking lost/reacquire 或 manual pause 标记为实体验收通过。
