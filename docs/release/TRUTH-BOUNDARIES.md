# 功能真实性边界

1. 官方课程来自苏州工艺美术职业技术学院与中国大学 MOOC。梨花季提供课程目录与跳转/嵌入入口，不声称已测试每节课播放完成；课程平台可能要求网络、登录或选课。
2. 梨花季 Stitch Lab 的针迹、路径、针落点和配色是项目数字示意。
3. 套针、滚针 demo 不是专家提供或逐针复原的传统刺绣原始数据。
4. 梨花瓣 56 针是项目数字设计参数。
5. 28 / 14 / 14 是该数字设计数据的分批数量，不是传统苏绣固定针数或工艺规则。
6. 11 秒是数字显影演示时长，不是实际刺绣时长或教学时长。
7. AR 是图像目标上的数字视觉展示；相机追踪会受手机、光线、对焦、距离、屏幕亮度和打印质量影响。合成相机流测试不等于实体相机测试。
8. Ricuci 是第三方机器刺绣文件工具，不是苏绣手工针法教学工具。梨花季通过官方 Web 页面接入，不接收、不保存用户选择的文件。
9. 机器刺绣针迹文件与苏绣传统手工针法不是同一体系。

另有已知限制：没有真实张力物理模拟；没有真实背面针路；没有专家审定针序；学习进度仅保存在当前浏览器，没有账号云同步；MOOC 受平台登录和网络影响；Ricuci 由第三方提供；AR表现因设备与目标质量而异。

当前验收状态为 **Browser Verified**。未完成实体手机验收，因此不能写作真机验收通过、Single-device RC 或 Cross-device RC，也不发布 `v1.0.0-rc.1` 标签。
