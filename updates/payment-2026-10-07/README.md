# 梨花季本地平台源码更新 · 2026-10-07

这里同步了原本地平台本轮改动，保留 GitHub Pages 展示站的现有布局和功能。`platform/` 是增量源码文件集，应合并到已有完整平台中；本目录不包含完整运行时、全部基础模块、模型和素材，不能单独启动。

## 已同步

- 微信支付、支付宝开源 SDK 接入，以及服务端金额、订单、签名校验与状态核对逻辑。
- 原支付弹窗、主动查询付款结果与超时/失败提示。
- 商品详情新增“前往淘宝购买”。链接与原商品 ID 严格匹配，导入为在售的 75 件商品符合条件；价格、规格、库存、付款和售后以淘宝为准。
- 部署环境模板、证书目录权限准备脚本、相关测试与第三方许可证。

## 验证边界

购买入口的 2 组 URL 边界测试和 5 组隔离浏览器验收通过，覆盖手机显示、键盘聚焦、商品链接、注册登录及购物车。外站请求在测试中拦截，只验证跳转目标，没有进行实际付款。未验证淘宝当前库存、可售状态和真实交易。

此前支付实现的 140 项后台测试和 8 组浏览器检查已通过，使用隔离数据库及模拟渠道响应；本轮没有把这些旧检查算作新增验收。测试代码不代表真实渠道已经上线。

## 尚未完成

- 梨花季永久公网交易后台没有部署。
- 原商户的网站支付权限、正式 AppID 与绑定关系仍未完成验证。
- 没有真实支付和退款验收，也没有淘宝订单自动同步。
- 本次没有新提交商户申请，没有购买服务。

GitHub Pages 仍为静态文化展示站，不运行这套后台，也不发布此目录。将来部署完整后台时须另行配置合适的在线运行环境及合法授权的商户参数。

不包含真实用户数据、商户证书、私钥、APIv3 密钥、生产 `.env`、模型或 Windows 运行时。依赖声明见 `platform/requirements.txt`；第三方许可见 `platform/docs/third-party-licenses/`。

完整本地平台的维护者可运行新增检查：

```text
node --test tests/shop-links.test.cjs
```

浏览器验收须在原完整项目、已安装 Playwright 的环境内，用 `tests/taobao_ui_server.py` 启动隔离服务后运行 `tests/taobao-browser-acceptance.cjs`。不要将测试服务公开到互联网。
